# Instructions du module témoin T16

Garder ce module optionnel : aucune sélection automatique dans la composition produit, aucun semis D1 au démarrage. Maintenir ensemble les contrats, le renderer portable, les opérations DataPort et les six suites. Les ressources UI n'emportent ni secret ni logique d'autorisation ; l'hôte et le moteur revérifient droits, audience, version et effet.

Les tests locaux sont une preuve de contrat. Une recette navigateur, Worker, Sites, Cloudflare ou ChatGPT reste distincte et doit utiliser une composition et des identités de test explicitement préparées.
