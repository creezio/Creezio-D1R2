# Fichiers du module témoin T16

- `module/manifest.json` et `module/generate-manifest.mjs` : contrats standard, deux widgets, ressources, outils et inventaires.
- `module/operations.ts`, `module/entry.server.ts` : lecture et renommage via DataPort.
- `ui/widgets/*` : HTML et renderer MCP Apps des deux types, plus modèle de message.
- `ui/workspace/view.tsx`, `ui/contributions.ts`, `ui/front.tsx` : vues témoins existantes, sans changement de l'UI Creezio.
- `plugin/*` : projection plugin du module.
- `ci/*`, `tests/*`, `gate.mjs` : six suites contractuelles et leur lanceur.
- `README.md`, `prd.md`, `CHANGELOG.md`, `LICENSE` : artefacts installés ; `AGENTS.md`, `interview.md`, `TODO.md`, `FILES.md` : validation locale.
