# Décisions de recette

Les fiches `alpha` et `beta` sont synthétiques. Le module n'attribue ni compte ni rôle ; l'hôte fournit acteur, audience et contexte et le moteur autorise chaque effet. Le type de widget ne remplace pas l'identité d'instance. Le rendu conserve un texte de repli MCP pour les clients sans UI. La mutation nécessite la révision de l'objet et une clé d'idempotence ; un résultat incertain se réconcilie avant tout nouvel essai.
