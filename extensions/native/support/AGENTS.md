# Support natif

Appliquer les AGENTS du dépôt et `docs/STANDARD-MODULE.md`. Le service emploie les opérations communes et les plans D1 du module, sans SQL dans les handlers ni accès privé aux modèles d'un autre module. La source des deux interfaces est le commit Creezio `6bd6507633b4c17bfc31206d82d1caa9a8af19af` : `packages/admin/ui/tickets-admin-client.tsx` et `packages/support/ui/support-client.tsx`.
