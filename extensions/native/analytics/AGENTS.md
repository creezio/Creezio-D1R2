# Portée du module

Respecter le standard `docs/STANDARD-MODULE.md`. Les fichiers de ce dossier définissent uniquement le module `creezio.analytics`. Ne lire ni modifier les tables runtime privées, et ne présenter aucune donnée déclarée comme une mesure automatique. Garder les six suites locales et l’intégration D1 alignées avec les contrats générés par `module/generate-manifest.mjs`.
