# Module OpenAI

La clé ne doit jamais être écrite dans les sources, sorties, journaux ou vues. Utiliser seulement la capacité coffre hôte et le port HTTP fournisseur à ressources fixes. Les handlers de configuration utilisent les plans D1 du moteur T06 ; aucun SQL libre ou effet externe n'est exécuté par un handler. Les opérations Conversations gardent la propriété des tours et événements. Les six suites déclarées doivent rester exécutables ; une suite de contrat ne remplace pas la recette OpenAI réelle.
