# Fichiers du module

- module/ : manifeste, modèles actuels, métadonnées et handlers des dix opérations ; documentation.ts lit les documents installés depuis la capacité immuable de l'hôte.
- ui/ : liste et fiche de module adaptées des composants Creezio originaux ; documentation.tsx présente PRD, README et changelog installés.
- plugin/ : déclarations des outils MCP administratifs ; `catalog.detail` annonce désormais la ressource du widget.
- ui/widgets/module-detail.html et module-detail.ts : fiche MCP Apps administrateur compilée au build, sans remplacement de Product Hub.
- ci/ et tests/ : six suites propres au module et leurs entrées réelles.
- README, prd, CHANGELOG : documentation de version installée.
- AGENTS, interview, TODO : développement et limites de qualification.

Le SDK de résolution et les adaptateurs d’archives appartiennent au socle ; les données privées head/plans/journal/plan-outcomes appartiennent à ce module. `plan-outcomes` conserve la confirmation ou l'annulation de chaque plan sans réécrire les anciens modèles.
