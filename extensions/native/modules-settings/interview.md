# Décisions acquises

Le responsable veut un socle de type WordPress avec modules standardisés et mises à jour indépendantes. Les dépendances entre modules sont obligatoirement déclarées. L’admin original reste la référence visuelle et fonctionnelle. L’application est unique ; les services fournisseurs restent externes.

Le GO de construction est acquis. Ce module n’ajoute ni droit premium décidé arbitrairement, ni publication Sites automatique, ni autorisation implicite sur les données. Les choix contractuels de licence restent différés.
