# Portée du module commun

Conserver le standard de module et le port `catalog.products@1.0.0`. Les handlers utilisent les ports D1/R2 du SDK, jamais SQL direct ni dépendance au schéma privé d’un fork. Prix en entier minor avec devise ; ne pas adapter les règles WinHub de lots, TVA, groupes ou stock. Les ressources widget sont des projections des opérations publiées, sans second backend. Garder les six suites et la recette d’intégration réelles.
