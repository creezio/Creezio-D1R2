# Décisions T29 et points ouverts

- Réemploi de l’assistant Creezio original limité au vocabulaire et aux cartes de statut/résultat ; son transport local et ses reprises automatiques ne sont pas repris.
- Service Hermes externe seulement, origine HTTPS et bearer dans le coffre. La version réelle est découverte par GET capabilities.
- `hermes.manage` admin et `hermes.use` admin/app sont séparés ; un stamp privé évite de donner le modèle de configuration aux utilisateurs use.
- La mutation de run doit lier un identifiant local, le principal, l’audience et la génération, puis conserver une issue inconnue sans nouvelle soumission.
- L’approbation POST est différée faute de fixture/version exacte ; aucun raccord Work T17 ou règle T24 dans ce module.
- Recette avec une instance autorisée encore nécessaire ; aucun secret ou résultat distant n’est simulé comme preuve de livraison.
