# Inventaire Stripe

`module/` contient le manifeste généré, douze modèles contextuels dont `stripe_offer`, les ressources GET/POST déclarées, les opérations administratives et app, les projections, le service et le mapper d'événements signés `webhook.ts`. `ui/` contient la page Facturation, la vue d'offres du front, leurs états de panneau et trois widgets. `plugin/` expose les opérations autorisées en MCP sans transformer le webhook en outil public ; ses deux skills séparent strictement l'administration Stripe de l'achat app. `ci/` et `tests/` fournissent les six suites de validation ; `tests/stripe/` dans le dépôt hôte qualifie le moteur D1 avec transport simulé. Aucun dossier n8n, SQL brut, dépendance fournisseur ou secret n'est copié dans le paquet.
