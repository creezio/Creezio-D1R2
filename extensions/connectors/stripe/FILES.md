# Inventaire Stripe

`module/` contient le manifeste généré, les six modèles contextuels, le descripteur GET, les opérations, les projections et le service. `ui/` contient la page Facturation, son état de panneau et le widget de lecture. `plugin/` expose les mêmes opérations en MCP. `ci/` et `tests/` fournissent les six suites de validation ; `tests/stripe/` qualifie l'intégration réelle moteur/D1/transport simulé. Aucun dossier n8n, SQL brut, dépendance fournisseur ou secret n'est copié dans le paquet.
