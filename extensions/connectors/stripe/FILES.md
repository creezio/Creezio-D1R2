# Inventaire Stripe

`module/` contient le manifeste généré, onze modèles contextuels, les ressources GET/POST déclarées, les opérations dont `subscription.cancel.set`, les projections, le service et le mapper d'événements signés `webhook.ts`. `ui/` contient la page Facturation, son état de panneau et le widget de lecture. `plugin/` expose les mêmes opérations en MCP, sans transformer le webhook en outil public. `ci/` et `tests/` fournissent les six suites de validation ; `tests/stripe/` dans le dépôt hôte qualifie le moteur D1 avec transport simulé. Aucun dossier n8n, SQL brut, dépendance fournisseur ou secret n'est copié dans le paquet.
