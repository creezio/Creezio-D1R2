# Meili — connexion externe

Cette première tranche connecte Creezio à une instance Meilisearch HTTPS déjà exploitée. Un administrateur saisit son origine et sa clé API dans le workspace. La clé est scellée dans le coffre natif, n’est jamais retournée ni stockée dans le panneau et n’est utilisée que par le port serveur déclaré. Aucun serveur Meili n’est installé ou maintenu par Creezio.

`config.read`, `config.set`, `config.key.set` et `config.key.revoke` sont des opérations administratives à révision CAS et clé de demande. Changer d’origine avec une clé encore scellée est refusé, même si la connexion a été désactivée : il faut révoquer la clé, changer l’origine puis enregistrer une nouvelle clé. `connection.check` est une lecture administrative distincte, accessible à un compte machine muni de `creezio.meili:read`. Elle fait au plus un GET déclaré `/indexes?limit=1` avec Bearer, puis ne retourne que `authenticated` et `status`. Une erreur d’authentification distante donne `key_rejected` ; aucune liste d’index, nom, total, document ou corps fournisseur ne sort. Les refus de permissions et les erreurs de transport restent distincts.

Le [GET de liste d’index Meilisearch](https://www.meilisearch.com/docs/reference/api/indexes/list-all-indexes) a été vérifié une fois avec un accès externe autorisé (HTTP 200, enveloppe JSON conforme, 181 octets ; reçu expurgé `CREEZIO-T28-MEILI-EXTERNAL-READONLY-2026-09-29.json`). Ce GET seul ne qualifie pas le module, ses transports ni son interface. Aucun index métier, aucune indexation, aucune recherche Meili et aucune interface de recherche globale ne sont livrés par cette tranche.

La recherche Catalogue `product.search` existante continue sans Meili. La recherche globale native T05 est reportée par l’utilisateur ; son raccord demandera une explication et un accord propres. REQ-2801 reste ouverte pour les écritures asynchrones, reconstruction, suppression, filtres contextuels, recherche et recette complète. Aucun POST fournisseur, daemon, scheduler ou service tiers embarqué n’est introduit ici.
