# Instructions du témoin

Périmètre : recette locale de compilation et runtime T-03. Conserver le caractère non sensible de la lecture, l'absence de données métier et l'exclusion de la composition par défaut. Ne pas ajouter de réussite factice pour l'authentification, le stockage ou un service tiers.

Maintenir le manifeste, les docs de version et les six suites. Aucun workflow de publication ni activation de hooks dans ce paquet. Le handler protégé ne doit jamais être invoqué avant l'authentification réelle. Les preuves et droits de publication appartiennent à l'application consommatrice.
