# @creezio/sdk 1.6.0 candidate

This package is the public authoring surface for Creezio modules. The 1.6.0 source and a locally packed archive are candidates, not a published release. Official archive availability, source revision and integrity are recorded in [GitHub Releases](https://github.com/creezio/Creezio-D1R2/releases). Published archives remain immutable; consumers retain their verified archive until an explicit update.

SDK 1.6 adds `OperationContext.operations?.query({moduleId, operationId, input})` for declared public reads and `OperationContext.diagnostics` for native analytics. An intermodule read requires a versioned public contract, a dependency and an `effects.calls` reference. The host retains identity, audience, context, cancellation and budgets. Nested commands are refused.

The candidate also declares bounded connector mutations, signed provider webhooks, provider search projections and durable connector deliveries. A mutation uses a fixed resource descriptor and the host credential; the handler never receives an arbitrary HTTP client or decrypted secret. A delivery declaration in `contracts.deliveries` binds an `on-invoke` command to a same-module prepare query, a public provider readiness contract, one connector resource and a module-owned receipt projector. The host records the intent before an outbound call, settles accepted or rejected receipts under current guards, and leaves uncertain outcomes for status inspection without repeating the provider call. These contracts do not add a scheduler or establish live provider qualification. See [the module standard](../docs/STANDARD-MODULE.md) and [the contract schemas](contracts/schemas/v1/README.md).

Earlier versions introduced the private widget image contract and `widgetCalls` binding (1.5), fixed canonical JSON command field validation (1.4.1), extended fixed GET connector resources (1.4), added linked file reads (1.3), and introduced the connector type and command journal subpaths (1.2). See [files/README.md](files/README.md) and [operations/README.md](operations/README.md). Modules import only declared package subpaths and declare the SDK version they require.

To build a local 1.6 candidate with Node 24, use the repository's existing dependencies and `sdk/dist`, then run `npm run sdk:build` and `npm pack --workspace sdk --ignore-scripts --json --pack-destination <existing-artifact-directory>` from the repository root. The `creezio-sdk-1.6.0.tgz` archive contains ESM JavaScript, declarations and versioned schemas. It excludes the root application, databases, secrets and Worker. The `@creezio/sdk/contracts/node` entry is Node-only; handlers and browser views must not import it. React and React DOM are shared peer dependencies.

Before any publication, qualify a clean `main` commit with CI and the consuming module archives. Record the exact commit and tree, package inventory, file hashes, tarball SHA-256 and byte count. Check every exported JavaScript and declaration path in the packed archive. Tag that exact commit and verify the uploaded release asset after download. A source checkout, local package, draft release or tag alone does not establish public availability; no npm registry publication is implied.
